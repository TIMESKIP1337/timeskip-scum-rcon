## 1. ทำงานอย่างไร

```
 คุณ (พรอมต์ rcon> หรือโปรแกรม RCON อื่น)
        │  ข้อความคำสั่ง
        ▼
 ScumRcon.Server  ── ตรวจล็อกอิน บทบาท ความยาว อัตราส่ง ──▶ audit log
        │  เขียนไฟล์เล็กๆ
        ▼
 <เซิร์ฟเวอร์>\...\ue4ss\Mods\ScumRcon\bridge\rcon_commands\
        │  ม็อดในเกมมาหยิบทุก 0.5 วินาที
        ▼
 ม็อด ScumRcon (อยู่ในโปรเซสเซิร์ฟเวอร์ SCUM ผ่าน UE4SS)
        │  รันเป็นคำสั่งแอดมิน หรือส่งข้อความแชท
        ▼
 เกม
```

มีสองส่วน และทั้งสองรันบน**เครื่องเดียวกัน**กับเกมเซิร์ฟเวอร์:

| ส่วน | คืออะไร | อยู่ที่ไหน |
|---|---|---|
| **ScumRcon.Server** | เซิร์ฟเวอร์ RCON (โปรแกรม .NET) รับคำสั่ง ตรวจสอบ แล้วส่งให้เกม | โฟลเดอร์ไหนก็ได้ เช่น `D:\ScumRcon` |
| **ม็อด ScumRcon** | ม็อด Lua เล็กๆ ที่รันในเกมผ่าน [UE4SS](https://github.com/UE4SS-RE/RE-UE4SS) | `...\SCUM\Binaries\Win64\ue4ss\Mods\ScumRcon` |

รีสตาร์ทเกมเซิร์ฟเวอร์ได้โดยไม่ต้องรีสตาร์ท ScumRcon.Server เพราะทั้งสองคุยกันผ่านไฟล์

## 2. สิ่งที่ต้องมี

* เครื่อง Windows ที่รัน **SCUM dedicated server**
* **.NET 8 runtime** (สำหรับรัน) หรือ **.NET 8 SDK** (สำหรับ build จากซอร์ส)
  <https://dotnet.microsoft.com/download/dotnet/8.0>
* **UE4SS** ในโฟลเดอร์ `Win64` ของเซิร์ฟเวอร์ **ไม่ได้รวมมาใน repo นี้** สคริปต์ติดตั้งในขั้นที่ 3 จะโหลดรุ่นทางการ
  มาตรวจให้
* ต้องมี**ผู้เล่นออนไลน์อย่างน้อยหนึ่งคน**ตอนรันคำสั่งเกม (ดู[ข้อจำกัด](#12-ข้อจำกัดที่ยังมี))

## 3. ติดตั้งทีละขั้น

ตัวอย่างใช้ `D:\SCUM-Server` เป็นเซิร์ฟเวอร์เกม และ `D:\ScumRcon` เป็นโฟลเดอร์ RCON server ให้เปลี่ยนเป็นของคุณ

### 3.1 เอาไฟล์มา

ดาวน์โหลดหรือ clone repo นี้ ตอนนี้ยังไม่มีไฟล์ที่ build สำเร็จรูป ให้ build เซิร์ฟเวอร์หนึ่งครั้ง:

```powershell
cd path\to\this\repository
dotnet publish src\ScumRcon.Server -c Release -o D:\ScumRcon
```

แล้วคัดลอกไฟล์ช่วยมาไว้ข้างกัน:

```powershell
Copy-Item clients\rcon-client.ps1        D:\ScumRcon\
Copy-Item extras\windows\Start-ScumRcon.bat D:\ScumRcon\
```

### 3.2 ติดตั้ง UE4SS

ปิดเกมเซิร์ฟเวอร์ก่อน แล้วรัน (PowerShell):

```powershell
.\scripts\Install-Ue4ss.ps1 -ServerBinaries 'D:\SCUM-Server\SCUM\Binaries\Win64'
```

สคริปต์ทำอะไร: โหลด UE4SS รุ่นทางการที่ตรึงไว้หนึ่งไฟล์ **ไม่ติดตั้งถ้า SHA-256 ไม่ตรง** วาง `dwmapi.dll` ข้าง
`SCUMServer.exe` และโฟลเดอร์ `ue4ss` ข้างกัน แล้วติดตั้งไฟล์ตั้งค่าจาก `extras\ue4ss\UE4SS-settings.scum-server.ini`

ทำไมต้องใช้ไฟล์ตั้งค่านั้น: ด้วยค่าเริ่มต้นของ UE4SS (เปิด hook เพิ่ม 8 ตัว) เซิร์ฟเวอร์ SCUM ที่ทดสอบ**ล่มทันทีที่ผู้เล่นคนแรกเข้าเกม**
ส่วน UE4SS build เดียวกันกับไฟล์ตั้งค่าของ repo นี้ไม่ล่ม ถ้าคุณมี UE4SS อยู่แล้ว สคริปต์จะไม่แตะ (ใส่ `-Force` เพื่อแทนที่ไฟล์โปรแกรม
ม็อดและไฟล์ตั้งค่าของคุณไม่ถูกเขียนทับ และไฟล์ที่ถูกแทนที่จะสำรองไว้) รายละเอียด:
[INSTALL.md](INSTALL.md#ue4ss-required-not-included-in-this-repository)

### 3.3 ติดตั้งม็อดในเกม

คัดลอกโฟลเดอร์ `mods\ScumRcon` ไปที่:

```
D:\SCUM-Server\SCUM\Binaries\Win64\ue4ss\Mods\ScumRcon
```

ไฟล์ว่าง `enabled.txt` ข้างในคือสวิตช์เปิดม็อด (หรือเพิ่มบรรทัด `ScumRcon : 1` ใน `ue4ss\Mods\mods.txt` เหนือบรรทัด
`Keybinds : 1`) ม็อดนี้ไม่ต้องใช้ม็อดอื่น

### 3.4 เปิดเกมเซิร์ฟเวอร์หนึ่งครั้ง

เปิด SCUM ตามปกติ แล้วเปิดไฟล์ `D:\SCUM-Server\SCUM\Binaries\Win64\ue4ss\UE4SS.log` มองหาบรรทัด:

```
[ScumRcon] RCON bridge active, polling for commands every 500 ms
```

ตอนนี้ม็อดสร้างสองโฟลเดอร์ที่ RCON server ต้องใช้แล้ว: `...\Mods\ScumRcon\bridge\rcon_commands` และ `...\rcon_responses`

### 3.5 เปิด RCON server ครั้งแรก

```powershell
cd D:\ScumRcon
.\ScumRcon.Server.exe
```

ครั้งแรกมันจะสร้าง `config\rcon.json` **แสดงรหัสผ่านแอดมินครั้งเดียว แล้วปิดตัวเอง**:

```
First run: created D:\ScumRcon\config\rcon.json
  Login : admin:<password>   (RCON password field = admin:XXXXXXXXXXXXXXXXXXXXXXXX)
  This password is shown ONCE and is stored only as a hash. Save it now.
```

เก็บรหัสผ่านไว้ในโปรแกรมจัดการรหัสผ่าน มันถูกเก็บเป็น hash เท่านั้น จึงแสดงซ้ำไม่ได้ (ถ้าต้องการรหัสใหม่ ดู[ผู้ใช้และบทบาท](#7-ผู้ใช้-บทบาท-และสิทธิ์))

### 3.6 แก้ `config\rcon.json`

เปิดด้วยโปรแกรมแก้ข้อความ สำหรับสะพานแบบไฟล์ต้องแก้ส่วน `bridge` (`config\rcon.example.json` มีทุกค่าให้ดู):

```json
"bridge": {
  "mode": "File",
  "commandsDirectory":  "D:\\SCUM-Server\\SCUM\\Binaries\\Win64\\ue4ss\\Mods\\ScumRcon\\bridge\\rcon_commands",
  "responsesDirectory": "D:\\SCUM-Server\\SCUM\\Binaries\\Win64\\ue4ss\\Mods\\ScumRcon\\bridge\\rcon_responses",
  "timeoutSeconds": 15
}
```

* `mode` ต้องเป็น `"File"` (ค่าเริ่มต้นคือ `"Tcp"` ซึ่งต้องใช้ปลั๊กอินฝั่งเกมอีกตัวที่ repo นี้ไม่ได้แถมมา)
* ใน JSON ต้องใส่ backslash สองตัว (`\\`)
* สองโฟลเดอร์ต้องเป็นพาธ**เต็ม**และต้อง**มีอยู่แล้ว** (ขั้น 3.4 สร้างไว้ให้)
* ปล่อย `listenAddress` เป็น `127.0.0.1` และ `port` เป็น `28015` ถ้าไม่จำเป็น (ดู[เชื่อมจากเครื่องอื่น](#เชื่อมจากเครื่องอื่น))

### 3.7 เปิดใช้งานจริง

```powershell
.\ScumRcon.Server.exe --console
```

หรือดับเบิลคลิก `Start-ScumRcon.bat` ถ้าค่าตั้งผิดพลาด โปรแกรมจะพิมพ์ปัญหาทุกข้อและไม่เริ่มทำงาน

## 4. เปิดใช้และพิมพ์คำสั่ง

### หน้าต่างเดียว (แนะนำ)

`Start-ScumRcon.bat` (หรือ `ScumRcon.Server.exe --console`) แสดงโลโก้ สถานะ และพรอมต์:

```
listening  127.0.0.1:28015
bridge     files   (a folder the game mod watches)
audit log  D:\ScumRcon\logs\audit.jsonl

rcon> ListPlayers
rcon> say global เซิร์ฟเวอร์จะรีสตาร์ทใน 5 นาที
rcon> saypm god 4 hello
rcon> exit
```

* พิมพ์คำสั่งแล้วกด Enter จะใส่ `#` นำหน้าหรือไม่ก็ได้ (`#ListPlayers` = `ListPlayers`)
* `exit` หรือ `quit` (หรือ Ctrl+C) ปิด RCON server เกมยังรันต่อ
* พรอมต์นี้ไม่ต้องใส่รหัสผ่าน เพราะมีไว้สำหรับคนที่นั่งหน้าเครื่องเซิร์ฟเวอร์ ทุกคำสั่งยังถูกบันทึกใน audit log ในชื่อผู้ใช้ `console`
* สีต้องใช้เทอร์มินัลรุ่นใหม่ (Windows Terminal, คอนโซล Windows 10/11) ตั้งตัวแปร `NO_COLOR` เพื่อปิดสี
  และถ้าส่งเอาต์พุตเข้าไฟล์ จะไม่มีรหัสสีปน
* **รัน ScumRcon.Server ได้ทีละตัวต่อหนึ่งค่าตั้ง** ตัวที่สองจะหยุดพร้อมข้อความที่เข้าใจง่าย

### จากหน้าต่างอื่น สคริปต์ หรือเครื่องอื่น

ขณะที่เซิร์ฟเวอร์รันอยู่ โปรแกรม RCON ใดๆ ต่อเข้ามาได้ การล็อกอินคือช่อง "password" ของ Source-RCON ใส่เป็น
**`user:password`** เช่น `admin:รหัสผ่านของคุณ`

ไคลเอนต์ PowerShell ที่แถมมา:

```powershell
.\rcon-client.ps1 -Command ListPlayers          # หนึ่งคำสั่ง แล้วจบ (ถามรหัสผ่านแบบซ่อน)
.\rcon-client.ps1                               # โหมดพิมพ์ต่อเนื่อง
.\rcon-client.ps1 -HostName 10.0.0.5 -Port 28015 -User moderator
```

รหัสผ่านพิมพ์ในช่องที่ซ่อน และไม่ถูกเก็บ โปรแกรม Source-RCON ตัวอื่นน่าจะใช้ได้ (โปรโตคอลมีเทสต์อัตโนมัติ) แต่ตัวที่ลองด้วยมือมีแค่สคริปต์ที่แถมมา

### เชื่อมจากเครื่องอื่น

RCON **ไม่เข้ารหัส** รหัสผ่านและคำสั่งวิ่งผ่านเครือข่ายเป็นข้อความธรรมดา ถ้าแอดมินต่อจากเครื่องอื่น ให้ส่งผ่าน VPN หรืออุโมงค์ SSH
ตั้ง `listenAddress` เป็นที่อยู่ VPN ใส่ใน `ipAllowlist` เฉพาะที่อยู่ที่อนุญาต (ใช้ CIDR เช่น `10.8.0.0/24` ได้ รายการว่าง = **ไม่ให้ใครเข้า**)
และเปิดพอร์ต RCON ในไฟร์วอลล์ให้เฉพาะที่อยู่เหล่านั้น **ห้ามเปิดพอร์ต 28016**

## 5. คำสั่งของเกม

### `players`: ใครออนไลน์อยู่ (ตอบที่นี่เลย)

```
rcon> players
2 players online:
1. Alice  76561198000000001
2. Bob  76561198000000002
```

คำสั่งนี้ม็อด ScumRcon ตอบเอง คุณจึง**เห็นรายชื่อจริง**ที่พรอมต์ (ส่วน `ListPlayers` ของเกมแสดงข้อความในเกมเท่านั้น) มันแสดงชื่อในเกมและ SteamID
ของทุกคนที่ออนไลน์ เรียงตามชื่อ และตอบ `No players online.` เมื่อเซิร์ฟเวอร์ว่าง ใช้ได้แม้ไม่มีใครออนไลน์และไม่ต้องมีผู้เล่นที่เป็นแอดมิน
ใช้หา SteamID สำหรับ `saypm` ได้ คำที่ตามมาถูกละเว้น และบทบาท `Viewer` ใช้ได้ตามค่าเริ่มต้น

**`ListPlayers` ทำเหมือนกัน** ม็อดตอบเองและ**ไม่ส่งเข้าเกมเด็ดขาด** โดยตั้งใจ เพราะ `ListPlayers` ของเกมจะพิมพ์ชื่อ, SteamID, ยอดเงิน และ
**ตำแหน่งของทุกคน** ลงในแชทในเกมของผู้เล่นหนึ่งคน สคริปต์และบอทที่ส่ง `ListPlayers` จึงได้รายชื่อของม็อด (มีแค่ชื่อกับ SteamID
และรูปแบบเป็นของม็อด ไม่ใช่ของเกม)

### อย่างอื่นทั้งหมด: คำสั่งแอดมินของเกม

ทุกอย่างที่ไม่ใช่ `say`, `saypm` หรือ `players` จะถูกส่งให้เกมเป็น**คำสั่งแอดมิน** เหมือนแอดมินพิมพ์ในแชทเกม ดังนั้นไวยากรณ์เป็นของเกมเอง
พิมพ์ `#Help` ในแชทเกมเพื่อดูรายการ

คำสั่งที่เคยรันผ่าน ScumRcon บนเซิร์ฟเวอร์ทดสอบและเห็นในล็อกของเกม:

```
ListPlayers
SpawnItem Weapon_AKM 1 76561198000000042 Location
Teleport X=-183753.672 Y=-213822.312 Z=32899.160 76561198000000042
announce สวัสดีทุกคน
SetImmortality true
settime 23:00
setweather 1
SetAttributesPlayer GOD 8 5 5 5
```

### ข้อความของเกมไปที่ไหน

เมื่อเกมรันคำสั่งแอดมิน มันพิมพ์ข้อความของคำสั่ง (รายชื่อผู้เล่น, ธง, ยานพาหนะ, ทีม, ข้อความยืนยัน...) ลงใน**แชทในเกมของผู้เล่นที่การเชื่อมต่อนั้นรันคำสั่ง**
ไม่ได้ส่งกลับมาหาคุณ ดังนั้น**คำสั่งแสดงรายการอาจเผยข้อมูลของผู้เล่นคนอื่น** (ตำแหน่ง, SteamID, เจ้าของ) บนหน้าจอของผู้เล่นคนนั้น เรื่องนี้เกิดขึ้นจริงบนเซิร์ฟเวอร์ทดสอบ:
การรัน `listplayers` ของเกมผ่าน RCON ทำให้ข้อมูลผู้เล่นทั้งหมดขึ้นบนหน้าจอของผู้เล่นที่การเชื่อมต่อของเขารันคำสั่ง ดังนั้น:

* **มีแต่แอดมินที่รันคำสั่งของคุณ** ม็อดรันคำสั่งเกมผ่านการเชื่อมต่อของ**ผู้เล่นที่ออนไลน์และอยู่ในรายชื่อแอดมินของเกมเอง**
  (`SCUM\Saved\Config\WindowsServer\AdminUsers.ini`) ถ้าไม่มีแอดมินออนไลน์ คำสั่งจะ**ถูกปฏิเสธ** (`No admin player is online...`) และไม่มีอะไรถูกส่งถึงใคร
  ถ้ามีแอดมินหลายคน คนแรกในรายชื่อผู้เล่นเป็นคนรัน ข้อความจะขึ้นในแชทของแอดมินคนนั้น และล็อกของม็อดบอกว่าใครรัน
  (`[RCON-Bridge] Running as admin <ชื่อ> (<steamid>)`)
* `ListPlayers` ม็อดจัดการเอง ไม่ส่งเข้าเกม (ดู [`players`](#players-ใครออนไลน์อยู่-ตอบที่นี่เลย))
* คำสั่งแสดงรายการของเกม (`ListFlags`, `ListSpawnedVehicles`, `DumpAllSquadsInfoList`, ...) **ไม่อนุญาต**สำหรับบทบาท `Viewer` ตามค่าเริ่มต้น
  ให้เฉพาะคนที่ไว้ใจ และรู้ไว้ว่าข้อความจะขึ้นในแชทของแอดมินคนหนึ่ง
* `say`, `saypm` และ `players` ไม่ต้องมีแอดมินออนไลน์

ม็อดอ่าน `AdminUsers.ini` เอง (หนึ่งบรรทัดคือ SteamID อาจตามด้วย `[Godmode]`) ถ้าไฟล์อยู่ที่อื่นหรืออ่านไม่ได้ จะตอบ `Cannot tell who the admins are...` ดู
[ค่าตั้งฝั่งเกม](#ค่าตั้งฝั่งเกมใน-mainlua)

ที่ควรรู้:

* คำสั่งรันในนามของแอดมินที่ออนไลน์อยู่ (เกมบันทึกคำสั่งไว้ในชื่อผู้เล่นคนนั้น) จึงต้องมี**แอดมินอยู่ในเกมอย่างน้อยหนึ่งคน** ไม่เช่นนั้นจะตอบ `No admin player is online...`
* **ข้อความที่เกมตอบกลับยังไม่ถูกส่งกลับมา**ที่พรอมต์ (ดู[ข้อจำกัด](#12-ข้อจำกัดที่ยังมี)) คำสั่งที่สำเร็จจะพิมพ์
  `Executed: <command> (the game sent no reply text)` คำสั่งนั้น*รันแล้วจริง* ให้ดูผลในเกม หรือในล็อกเซิร์ฟเวอร์
  (`SCUM\Saved\Logs\SCUM.log` บรรทัด `Command: '...'`) ถ้าต้องการรายชื่อผู้เล่น ใช้ `players` ข้างบน
* คำสั่งใส่เครื่องหมายคำพูด `"` หรือ backslash `\` ไม่ได้ (สะพานแบบไฟล์ส่งอย่างปลอดภัยไม่ได้) โปรแกรมจะปฏิเสธพร้อมข้อความ
  แทนที่จะส่งของที่เสียหายไป
* ความยาวคำสั่งสูงสุดคือ `maxCommandLength` (เริ่มต้น 512) อักขระควบคุมถูกปฏิเสธ

## 6. `say` และ `saypm`: ข้อความแชท

สองคำสั่งนี้ม็อด ScumRcon จัดการเอง ไม่ผ่านระบบแอดมินของเกม แสดงข้อความในแชทของผู้เล่น

```
say    [ช่อง] <ข้อความ>                     ส่งถึงทุกคนที่ออนไลน์
saypm  <ชื่อ หรือ steamid> [ช่อง] <ข้อความ>  ส่งถึงผู้เล่นคนเดียว
```

ตัวอย่าง:

```
say global เซิร์ฟเวอร์จะรีสตาร์ทใน 5 นาที
say 4 เฉพาะแอดมินนะ
saypm god 4 hello
saypm GOD admin ยินดีต้อนรับกลับ
saypm 76561198000000042 squad ต้องการคุณที่เบส
saypm god ข้อความส่วนตัว              (ไม่ใส่ช่อง = "server")
```

### ช่อง

**สี**ของแชทมาจากช่อง ไม่ใช่จากข้อความ

| เลข | ชื่อ | หมายเหตุ |
|---|---|---|
| 0 | `default` | |
| 1 | `local` | |
| 2 | `global` | สีฟ้าอมเขียวในการทดสอบ |
| 3 | `squad` | สีเขียวในการทดสอบ |
| 4 | `admin` | สีเหลืองในการทดสอบ |
| 5 | `commands` / `commandsonly` | |
| 6 | `server` / `servermessage` | **ใช้เมื่อไม่ระบุช่อง** |
| 7 | `error` | |

(ตรวจดูบนหน้าจอแล้วเฉพาะช่อง 2, 3 และ 4) ใช้เลขหลักเดียว 0-7 หรือชื่อก็ได้ `say 12 hi` จะถูกปฏิเสธ

### ส่งถึงใคร

* `say` ส่งถึง**ทุกคนที่เชื่อมต่ออยู่** คำตอบบอกจำนวน (`to 3 player(s)`)
* `saypm` ส่งถึง**คนเดียว** คำแรกหลัง `saypm` คือเป้าหมาย:
  * **ตัวเลข 10 หลักขึ้นไป** = SteamID
  * **อย่างอื่น** = **ชื่อในเกม**ของผู้เล่น (ต้องตรงทั้งชื่อ ไม่สนตัวพิมพ์เล็กใหญ่ของตัวอักษรอังกฤษ: `god` หา `GOD` เจอ)
* **ชื่อต้องเป็นคำเดียว** (ไม่มีเว้นวรรค) เพราะส่งเครื่องหมายคำพูดไม่ได้ ถ้าชื่อมีเว้นวรรคให้ใช้ SteamID
* ถ้า**ผู้เล่นออนไลน์สองคนชื่อเหมือนกัน** จะไม่ส่งอะไรและแจ้ง SteamID ให้เลือก
* ถ้าไม่เจอใคร: `No online player named X` / `No online player with SteamID X`

### ชื่อนำหน้า

บรรทัดเริ่มด้วยชื่อ เพื่อให้ผู้เล่นรู้ว่าใครพูด: `[TIMESKIPCON] เซิร์ฟเวอร์จะรีสตาร์ทใน 5 นาที` เกมไม่แสดงชื่อผู้ส่งให้บรรทัดที่ไม่มีผู้เล่นจริงอยู่เบื้องหลัง
ม็อดจึงเขียนชื่อลงในตัวข้อความ แก้ได้ที่หัวไฟล์ `mods\ScumRcon\Scripts\main.lua`:

```lua
if RCON_SAY_NAME == nil then RCON_SAY_NAME = "TIMESKIPCON" end
```

ใส่ `RCON_SAY_NAME = ""` ถ้าไม่ต้องการชื่อ ยาวได้ 32 ไบต์ (ภาษาไทยประมาณ 10 ตัวอักษร) รีสตาร์ทเกมเซิร์ฟเวอร์เพื่อให้มีผล

### ข้อจำกัด

ข้อความยาว 400 ตัวอักษร ห้ามมี `"` หรือ `\` ภาษาอื่น (เช่นไทย) ใช้ได้

## 7. ผู้ใช้ บทบาท และสิทธิ์

ทุกการล็อกอินมี**บทบาท**:

| บทบาท | ความหมาย |
|---|---|
| `Viewer` | ต่ำสุด |
| `Moderator` | |
| `Admin` | สูงสุด รวมทุกอย่างที่ต่ำกว่า |

แต่ละคำสั่งมี**บทบาทขั้นต่ำ**ใน `commandRoles` (ใช้คำแรกของคำสั่ง ไม่สนตัวพิมพ์ ไม่นับ `#`) **คำสั่งที่ไม่ได้ลงรายการต้องเป็น `Admin`**
ไม่รู้จัก = จำกัด ไม่ใช่เปิดให้

ค่าเริ่มต้นให้ `Viewer` รันได้เฉพาะ:

```json
"commandRoles": {
  "help": "Viewer",
  "ListPlayers": "Viewer",
  "players": "Viewer"
}
```

(`ListPlayers` ม็อดตอบเอง ดู [`players`](#players-ใครออนไลน์อยู่-ตอบที่นี่เลย) ส่วนคำสั่งแสดงรายการของเกมเอง เช่น `ListFlags` หรือ
`ListSpawnedVehicles` **ไม่อยู่**ในค่าเริ่มต้น ดู[ข้อความของเกมไปที่ไหน](#ข้อความของเกมไปที่ไหน))

ให้ผู้ดูแล (moderator) ส่งข้อความแชทและประกาศได้:

```json
"say": "Moderator",
"saypm": "Moderator",
"announce": "Moderator"
```

พรอมต์ `rcon>` ในหน้าต่างเซิร์ฟเวอร์ทำงานเป็น `Admin` เสมอ

### เพิ่มผู้ใช้

1. สร้าง hash รหัสผ่าน: `.\ScumRcon.Server.exe --hash-password` (ถามรหัสผ่าน **ตัวอักษรที่พิมพ์มองเห็นได้**) คัดลอกบรรทัดที่พิมพ์ออกมา (ขึ้นต้นด้วย `pbkdf2-sha256$`)
2. เพิ่มผู้ใช้ใน `config\rcon.json`:

```json
"users": [
  { "name": "admin",     "passwordHash": "pbkdf2-sha256$600000$...", "role": "Admin" },
  { "name": "moderator", "passwordHash": "pbkdf2-sha256$600000$...", "role": "Moderator" }
]
```

3. รีสตาร์ท ScumRcon.Server ชื่อ: 1-32 ตัว เป็นตัวอักษร ตัวเลข `_` `.` หรือ `-` และห้ามซ้ำ

**ลืมรหัสผ่านแอดมิน?** รัน `--hash-password` กับรหัสใหม่แล้วแทน `passwordHash` ของผู้ใช้นั้น (หรือลบ `config\rcon.json` เพื่อเริ่มใหม่ จะได้รหัสผ่านแอดมินสุ่มใหม่)

## 8. รายการตั้งค่า

`config\rcon.json` (ใส่คอมเมนต์ `//` และ comma ท้ายรายการได้) ค่าเริ่มต้นอยู่ในวงเล็บ

| ค่า | ความหมาย |
|---|---|
| `listenAddress` [`127.0.0.1`] | ที่อยู่ที่ RCON server ฟัง loopback = เครื่องนี้เท่านั้น |
| `port` [`28015`] | พอร์ต RCON |
| `ipAllowlist` [`127.0.0.1`, `::1`] | ใครต่อได้: ที่อยู่หรือช่วง CIDR **ว่าง = ไม่ให้ใคร** `0.0.0.0/0` ถูกปฏิเสธ |
| `maxConnections` [10] | จำนวนการเชื่อมต่อพร้อมกัน |
| `authTimeoutSeconds` [15] | เวลาที่ให้ล็อกอิน |
| `idleTimeoutSeconds` [300] | การเชื่อมต่อที่เงียบจะถูกตัดหลังเวลานี้ |
| `maxFailedAuth` [5], `failureWindowMinutes` [10], `blockMinutes` [15] | ล็อกอินผิด 5 ครั้งใน 10 นาที จะบล็อกที่อยู่นั้น 15 นาที |
| `maxCommandsPerSecond` [5] | จำกัดอัตราต่อการเชื่อมต่อ |
| `maxCommandLength` [512] | 1 ถึง 2048 |
| `users` | ดู[ผู้ใช้](#7-ผู้ใช้-บทบาท-และสิทธิ์) |
| `commandRoles` | บทบาทขั้นต่ำต่อคำสั่ง |
| `bridge.mode` | `"File"` (ใช้ตัวนี้) หรือ `"Tcp"` |
| `bridge.commandsDirectory`, `bridge.responsesDirectory` | พาธเต็มของสองโฟลเดอร์สะพาน (โหมด File) |
| `bridge.timeoutSeconds` [15] | รอเกมนานเท่าไร |
| `bridge.host`, `bridge.port`, `bridge.secret` | สำหรับสะพาน TCP เท่านั้น ([BRIDGE-PROTOCOL.md](BRIDGE-PROTOCOL.md)) |
| `auditLogPath` [`logs/audit.jsonl`] | ที่เขียน audit log |

โปรแกรม**ไม่เริ่มทำงาน** (และบอกเหตุผล) ถ้า: ที่อยู่ไม่ใช่ IP, ตัวเลขเกินช่วง, allowlist เปิดให้ทั้งอินเทอร์เน็ต, ที่อยู่ที่ไม่ใช่ loopback แต่ allowlist ว่าง,
ชื่อผู้ใช้ไม่ถูกต้องหรือซ้ำ, hash รหัสผ่านไม่ถูกต้อง, บทบาทไม่รู้จัก, หรือโฟลเดอร์สะพานไม่มี

ใช้ไฟล์ตั้งค่าอื่นด้วย `ScumRcon.Server.exe --config D:\other\rcon.json`

### ค่าตั้งฝั่งเกมใน `main.lua`

ม็อดมีค่าตั้งไม่กี่ตัวที่หัวไฟล์ `mods\ScumRcon\Scripts\main.lua` (รีสตาร์ทเกมเซิร์ฟเวอร์หลังแก้):

| ค่า | ความหมาย |
|---|---|
| `RCON_SAY_NAME = "TIMESKIPCON"` | ชื่อนำหน้าบรรทัดของ `say` และ `saypm` `""` = ไม่มีชื่อ ยาวได้ 32 ไบต์ |
| `RCON_EXECUTOR = "any"` | **ไม่แนะนำ** คำสั่งจะรันผ่านผู้เล่นคนแรกที่เจอ ไม่ใช่แอดมิน ผลลัพธ์จึงขึ้นในแชทของผู้เล่นคนไหนก็ได้ ถ้าไม่มีบรรทัดนี้ จะใช้เฉพาะแอดมิน |
| `RCON_ADMIN_USERS_FILE = "..\\..\\Saved\\Config\\WindowsServer\\AdminUsers.ini"` | ที่อยู่ของรายชื่อแอดมินของเกม เทียบกับโฟลเดอร์ `Win64` (หรือพาธเต็ม) ต้องตั้งเฉพาะเมื่อไฟล์ของคุณอยู่ที่อื่น |
| `RCON_BRIDGE_DIR = "ue4ss\\Mods\\ScumRcon\\bridge"` | โฟลเดอร์แลกเปลี่ยน เทียบกับ `Win64` ต้องตรงกับ `bridge.commandsDirectory` และ `responsesDirectory` |

บรรทัดที่ขึ้นต้นด้วย `--` คือค่าเริ่มต้น นอกจากนี้ ไฟล์ว่าง `ue4ss\Mods\ScumRcon\debug.txt` เปิดการบันทึก debug

## 9. log และบันทึกการตรวจสอบ

`logs\audit.jsonl` มีหนึ่งอ็อบเจกต์ JSON ต่อบรรทัด ไม่เขียนรหัสผ่านเด็ดขาด

| `event` | ความหมาย |
|---|---|
| `auth_ok` / `auth_fail` | ล็อกอินสำเร็จ / ไม่สำเร็จ (`blockedNow` บอกว่าครั้งนี้ทำให้ถูกบล็อกหรือไม่) |
| `blocked` | ที่อยู่ที่ถูกบล็อกพยายามต่อ |
| `rejected_ip` | ที่อยู่ไม่อยู่ใน `ipAllowlist` |
| `cmd` | คำสั่งถูกรัน (`user`, `role`, `command`, `success`) พรอมต์จะขึ้นเป็นผู้ใช้ `console` และ `ip` เป็น `local` |
| `cmd_denied` | คำสั่งถูกปฏิเสธ (`reason`: บทบาทต่ำเกินไป, ยาวเกิน, มีอักขระควบคุม) |
| `rate_limited`, `too_many_connections`, `auth_timeout`, `idle_timeout`, `protocol_error`, `session_error` | ปัญหาการเชื่อมต่อ |

ฝั่งเกม: `ue4ss\UE4SS.log` มีบรรทัดของม็อด (`[ScumRcon]`, `[RCON-Bridge] Executing: ...`)
เปิด**โหมด debug**เพื่อให้ log มากขึ้น: สร้างไฟล์ว่าง `ue4ss\Mods\ScumRcon\debug.txt` แล้วรีสตาร์ทเกมเซิร์ฟเวอร์ (ลบไฟล์เพื่อปิด)
มันบันทึกว่าฟังก์ชันไหนของเกมทำงานรอบคำสั่ง มีไว้สำหรับนักพัฒนา

## 10. แก้ปัญหา

| สิ่งที่เห็น | สาเหตุและวิธีแก้ |
|---|---|
| `No connection could be made because the target machine actively refused it` | ScumRcon.Server ไม่ได้รันอยู่ (หรือพอร์ตไม่ตรง) เปิดมัน ตรวจ `port` |
| `Login failed` | ผู้ใช้หรือรหัสผ่านผิด, ที่อยู่ไม่อยู่ใน `ipAllowlist`, หรือถูกบล็อก 15 นาทีหลังผิด 5 ครั้ง ช่อง password คือ `user:password` |
| `Cannot open the audit log ... Is another ScumRcon.Server already running` | มีอีกตัวรันอยู่ ปิดมัน (Task Manager หรือพิมพ์ `exit` ในหน้าต่างนั้น) |
| `Cannot listen on ...: the port is already in use` | โปรแกรมอื่นใช้พอร์ตนี้ ปิดมันหรือเปลี่ยน `port` |
| `The bridge folder does not exist` | เปิดเกมหนึ่งครั้งพร้อมม็อด (มันสร้างโฟลเดอร์ให้) หรือสร้างเอง และแก้พาธใน `bridge` |
| `Error: The game did not pick up the command. Is the game server running with the ScumRcon mod loaded?` | เกมปิดอยู่ หรือม็อดไม่โหลด ดู `UE4SS.log` ว่ามี `[ScumRcon] RCON bridge active` |
| `Error: No admin player is online. The game runs admin commands in the name of an online player...` | ไม่มีใครจาก `AdminUsers.ini` อยู่ในเกม เข้าเกมเป็นแอดมินแล้วลองใหม่ (`say`, `saypm`, `players` ใช้ได้โดยไม่ต้องมีแอดมิน) |
| `Error: Cannot tell who the admins are: cannot read ...AdminUsers.ini` | ม็อดหารายชื่อแอดมินของเกมไม่เจอ ตั้ง `RCON_ADMIN_USERS_FILE` ใน `mods\ScumRcon\Scripts\main.lua` (ดู[ค่าตั้งฝั่งเกม](#ค่าตั้งฝั่งเกมใน-mainlua)) |
| `Error: Failed to execute` | เกมปฏิเสธการเรียก ลองใหม่ ถ้ายังเป็นอยู่ให้ดู `UE4SS.log` |
| `Executed: ... (the game sent no reply text)` | ปกติในตอนนี้: คำสั่งรันแล้ว แต่ข้อความตอบของเกมยังไม่ถูกส่งกลับ (ดูข้อจำกัด) |
| `No online player named X` | ชื่อต้องตรงทั้งชื่อในเกม ชื่อที่มีเว้นวรรคต้องใช้ SteamID |
| `More than one online player named X` | ใช้ SteamID จากคำตอบ |
| `Denied: 'xyz' needs the Admin role.` | เพิ่มคำสั่งใน `commandRoles` ให้บทบาทนั้น หรือล็อกอินเป็น Admin |
| `The configuration has problems...` | แก้ตามบรรทัดที่ระบุ |
| `UE4SS.log` ไม่มีบรรทัด `[ScumRcon]` | โฟลเดอร์ม็อดอยู่ผิดที่หรือไม่มี `enabled.txt` พาธต้องเป็น `...\ue4ss\Mods\ScumRcon\Scripts\main.lua` |
| เกมเซิร์ฟเวอร์ **crash ตอนผู้เล่นเข้าเกม** | ตรวจว่า `ue4ss\UE4SS-settings.ini` คือไฟล์จาก `extras\ue4ss` (บรรทัด `Hook...` เป็น 0) ด้วยค่าเริ่มต้นของ UE4SS เกิดเหตุนี้ในการทดสอบของเรา |
| หน้าต่าง debug ของ UE4SS ขึ้นมา | ใน `UE4SS-settings.ini` หัวข้อ `[Debug]` ตั้ง `ConsoleEnabled`, `GuiConsoleEnabled`, `GuiConsoleVisible` เป็น `0` (ไฟล์ที่แถมมาตั้งเป็น `1` ตามค่าที่ทดสอบแล้ว การปิดยังไม่ได้อยู่ในการทดสอบ crash) |

## 11. รายการตรวจความปลอดภัย

1. ให้ `listenAddress` เป็น `127.0.0.1` เว้นแต่แอดมินต่อจากที่อื่นจริงๆ ถ้าต้องต่อ ให้ใช้ VPN หรืออุโมงค์ SSH
2. ให้ `ipAllowlist` สั้นที่สุด ห้ามเปิดพอร์ต 28016
3. ให้บทบาทต่ำสุดที่ทำงานได้ และลงรายการเฉพาะคำสั่งที่จำเป็น และจำไว้ว่าผลลัพธ์ของคำสั่งเกมจะขึ้นในแชทของผู้เล่น ([รายละเอียด](#ข้อความของเกมไปที่ไหน))
4. ใครเขียนไฟล์ลงโฟลเดอร์ `rcon_commands` ของสะพานได้ ก็รันคำสั่งแอดมินได้ ให้สิทธิ์โฟลเดอร์นั้นเฉพาะบัญชีที่รัน ScumRcon.Server และแอดมิน
5. อย่านำ `config\rcon.json` และ `logs\` ขึ้น Git หรือใส่ในไฟล์สำรองที่แชร์
6. เปิดดู `logs\audit.jsonl` เป็นระยะ หา `auth_fail`, `blocked`, `cmd_denied`
7. ดาวน์โหลด UE4SS จาก release ทางการเท่านั้น (สคริปต์ทำให้และตรวจ hash)

ดู [SECURITY.md](../SECURITY.md) สำหรับสิ่งที่โปรเจกต์รับรองและวิธีรายงานช่องโหว่

## 12. ข้อจำกัดที่ยังมี

* **ข้อความที่เกมตอบกลับยังไม่ถูกส่งกลับ** ม็อดฟังข้อความแชทที่เกมส่งกลับ แต่ในการทดสอบจริงกับ `ListPlayers` จับได้ 0 บรรทัด คำสั่งรันได้
  แต่คุณเห็นแค่ `Executed: ...` ส่วน `say`, `saypm` และ `players` ตอบเป็นข้อความจริง เพราะม็อดสร้างข้อความนั้นเอง สาเหตุที่น่าจะเป็น:
  เกมน่าจะส่งผลลัพธ์ของคำสั่งผ่านฟังก์ชันภายใน ไม่ใช่ผ่านแชท และการอ่านมันต้องใช้โค้ดเนทีฟ (C++) ที่ผูกกับเกมรุ่นใดรุ่นหนึ่ง ยังเป็นงานค้าง
* คำสั่งเกมต้องมี**ผู้เล่นที่เป็นแอดมินอยู่ในเกม** (ชื่ออยู่ใน `AdminUsers.ini` ของเกม) เพราะเกมรันคำสั่งในนามผู้เล่นคนนั้นและแสดงข้อความในแชทของเขา
  ถ้าไม่มีแอดมินออนไลน์ คำสั่งจะถูกปฏิเสธ ส่วน `say`, `saypm` และ `players` ยังใช้ได้ กฎ "เฉพาะแอดมิน" ทดสอบกับเกมจำลองแล้ว
  **ยังไม่ได้ยืนยันกับเซิร์ฟเวอร์จริงที่มีหลายผู้เล่น**
* ห้ามมี `"` หรือ `\` ในคำสั่ง และชื่อใน `saypm` ต้องเป็นคำเดียว
* UE4SS อาจพังเมื่อ SCUM อัปเดต ให้เก็บรุ่นที่ทดสอบไว้ รุ่นที่ตรึงไว้ทดสอบกับเซิร์ฟเวอร์เดียว ผู้เล่นหนึ่งคน เวลาไม่กี่นาที
* โหมดสะพาน TCP มีเอกสาร ([BRIDGE-PROTOCOL.md](BRIDGE-PROTOCOL.md)) แต่ไม่ได้แถมปลั๊กอินฝั่งเกมให้ ใช้สะพานแบบไฟล์
* ยังเป็น alpha ระยะแรก: ยังไม่ได้ตรวจกับเซิร์ฟเวอร์ที่มีผู้เล่นหนาแน่น

## 13. อัปเดตและถอนการติดตั้ง

**อัปเดต ScumRcon.Server:** ปิดมัน (`exit`) build ใหม่ด้วย `dotnet publish ... -o D:\ScumRcon` แล้วเปิด `config\` และ `logs\` ไม่ถูกแตะ

**อัปเดตม็อด:** คัดลอก `mods\ScumRcon` ใหม่ทับของเก่า (เก็บส่วนที่คุณแก้ใน `main.lua` เช่น `RCON_SAY_NAME`) แล้วรีสตาร์ทเกมเซิร์ฟเวอร์

**ถอนการติดตั้ง:** ปิด ScumRcon.Server ลบโฟลเดอร์ของมัน ลบ `ue4ss\Mods\ScumRcon` ถ้าจะถอด UE4SS ให้ลบ `dwmapi.dll`
และโฟลเดอร์ `ue4ss` ออกจาก `Win64` (สคริปต์ติดตั้งสำรองไฟล์ที่แทนที่ไว้ใน `ue4ss-backup-<เวลา>`)
